## 📊 Data Storage

### Table: `contact_messages`
Stores all contact form submissions.

| Field | Type | Description |
|---|---|---|
| id | text | Auto-generated UUID |
| name | text | Sender's full name |
| email | text | Sender's email |
| budget | text | Selected project budget |
| message | rich_text | Project description |
| timestamp | datetime | Submission time |

**API Endpoint:** `GET/POST tables/contact_messages`
